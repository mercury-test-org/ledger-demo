# Onboarding

Welcome to the ledger team!

1. Clone `mercury-test-org/ledger-demo` and run `go test ./...`.
2. Install `sdocs`, then run `sdocs init` and `sdocs login` in the repo.
3. Run `sdocs unseal docs/*.md` to read the sections your role can see.

Ask for access to the staging environment in #ledger-access.
